# Lớp Học Thông Minh AI V5.3 — Android APK Builder

This repository packages the V5.3 web app into an Android APK using Capacitor and GitHub Actions.

## Build
Open Actions → Build Android APK → Run workflow. Download the `Lop-Hoc-Thong-Minh-AI-V5.3-debug-apk` artifact and extract `app-debug.apk`.

The app requires network access for Firebase and remote libraries. This debug APK is for testing, not Play Store release signing.
